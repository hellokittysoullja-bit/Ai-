# Продуктовый аудит «Напарника» — v2

Дата: 2026-07-26. Скоуп: весь репозиторий — лендинг (6 секций), приложение
(Дом / Фокус / Мир), чат, память, система наград, маскот, сцена, звук,
service worker, API-роуты, CSS. Режимы: лендинг = Persuade, приложение =
Operate. Аудит — фаза 5 конвейера, без правок кода.

**Вердикт.** Ремесло продукта — уровень, который редко встречается в вебе:
рукокодный маскот с двухточечным освещением и перф-гейтом, честный таймер,
скриптовый мозг-фолбэк с анти-повтором, pity-система, прощение как дефолт.
Но при взгляде нейробиолога петля собрана с **тремя системными ошибками
архитектуры подкрепления**, а при взгляде маркетолога у продукта **ноль
петель привлечения и ноль измерений**. Ремесло — 9/10, машина вовлечения —
6/10. Ниже — почему и что делать.

# Слой 1 · Нейрохимия петли (главное)

## 1.1 Подкрепление приходит не за то поведение, которое мы тренируем

```
ГДЕ    — components/focus-session.tsx: recordStart() в start(),
         вся сенсорика награды (RevealIsland, chime, haptic) — в finish()
ЧТО    — валюта продукта — СТАРТ («старт засчитывается в момент нажатия»),
         но дофаминовый пик выплачивается через 15–45 минут, в финале.
         В момент старта человек получает только тихий выдох и мелкую
         mono-подпись «старт засчитан»
ПОЧЕМУ — это ошибка временной смежности подкрепления. У СДВГ-мозга
         крутое дисконтирование отсроченного вознаграждения: награда
         через 15 минут почти не подкрепляет действие, совершённое
         сейчас. Мы тренируем нажатие кнопки старта — а платим за
         досиживание. Поведенчески продукт вознаграждает НЕ то, что
         декларирует своей главной ценностью
ВМЕСТО — расщепить награду на два такта, как это делает вся жанровая
         классика (посадка семени / сбор урожая):
         (1) в момент старта — на острове ПРОКЛЁВЫВАЕТСЯ росток нового
         элемента: 1.5 сек видимого прорастания + haptic + текущий выдох.
         Немедленное, смежное по времени подкрепление именно инициации;
         (2) в финале — росток РАСПУСКАЕТСЯ в полный элемент (текущая
         хореография RevealIsland). Ранний выход — росток всё равно
         распускается (asymmetry «бонус без штрафа» сохраняется).
         Стоимость: RevealIsland уже умеет фазу anticipation — это
         перекомпоновка, не новая система
```

## 1.2 Награда с нулевой ошибкой предсказания: реведил без «reveal»

```
ГДЕ    — components/home-screen.tsx (goal-gradient карточка «Следующий
         старт вырастит „Костёр“» + призрачный силуэт), island.tsx
         (призраки с именами), reveal-island.tsx (фаза anticipation)
ЧТО    — для стартов 1–10 продукт заранее называет и показывает награду.
         К моменту финала исход известен на 100% — и хореография
         предвкушения (дыхание света, такт 850 мс) отыгрывает саспенс,
         которого для мозга не существует
ПОЧЕМУ — дофаминовый ответ пропорционален ошибке предсказания (RPE).
         Полностью предсказанная награда даёт всплеск в момент ПОДСКАЗКИ
         (карточка на Доме), а в момент выдачи — ноль. Первые 10 наград —
         формально самые важные (формирование привычки) — нейрохимически
         пустые. Дальше — обрыв: старт 11 внезапно включает variable
         ratio. Градиент неопределённости должен расти плавно, а не
         ступенькой
ВМЕСТО — лестница неопределённости:
         старты 1–3 — полная предсказуемость (доверие новичка, как сейчас);
         старты 4–10 — тизер категорией, не именем: «что-то тёплое уже
         проклёвывается у берега» + силуэт БЕЗ подписи. Предвкушение
         получает реальную информационную щель (curiosity gap);
         старты 11+ — текущий вероятностный пул.
         Один условный оператор в buildFirstWord/тизерах, эффект — живой
         RPE на всём онбординге
```

## 1.3 Петля привычки без сигнала: cue → routine → reward, где cue?

```
ГДЕ    — lib/checkin.ts (Periodic Background Sync = только Chrome/Android
         PWA), plan.startTime (собирается LLM-планировщиком, нигде не
         используется), favoriteHour (вычисляется, показывается строкой)
ЧТО    — рутина и награда сконструированы на AAA-уровне, но у петли нет
         СИГНАЛА: «он пишет первым» — заглавное обещание (title сайта,
         шаг «09:12» в how-it-works) — технически не существует для iOS
         Safari, Firefox, десктопного Safari и любого не-установленного
         Chrome. Возврат держится на памяти пользователя — ровно того
         ресурса, дефицит которого продукт обещает компенсировать
ПОЧЕМУ — привычка не формируется без стабильного триггера. Продукт
         собирает данные для идеального триггера (план + время + любимый
         час стартов) и выбрасывает их
ВМЕСТО — иерархия честных сигналов:
         (1) Web Push (VAPID + минимальный эндпоинт; payload обезличен —
         «первое слово ждёт», приватность почти не тронута) — работает
         на установленной PWA iOS 16.4+, Android, десктопах;
         (2) до сервера — .ics-файл «первое слово в 09:00» из plan.startTime
         в один тап на финальном экране (нулевая инфраструктура);
         (3) копи-фикс: там, где пуш недоступен, обещание «пишу первым»
         менять на уже честное «утром первое слово за мной — просто
         открой» (finish-экран это уже говорит правильно)
```

## 1.4 Остров без агентности: дневник, в котором нельзя писать

```
ГДЕ    — lib/island-sprites.tsx findPosition (позиция из сида),
         components/reveal-island.tsx
ЧТО    — человек не принимает НИ ОДНОГО решения о своём острове: место
         роста детерминировано сидом, элемент — розыгрышем. Он зритель
         собственного дневника
ПОЧЕМУ — эффект ИКЕА и эндаумент растут из вложенного решения, а не из
         наблюдения. Имя существу — единственный акт присвоения в
         продукте, и он работает; остров такого акта не имеет. Animal
         Crossing и вся жанровая ветка «мой уголок» держат удержание
         именно на агентности размещения
ВМЕСТО — микрорешение на пике: после прорастания — «куда посадим?» и
         2–3 подсвеченных места на острове, один тап (для reduced-motion
         и нетерпеливых — авторазмещение по сиду, как сейчас). Сид
         остаётся фолбэком; UI-цена — один экранный такт
```

## 1.5 Дефолт против собственной философии

```
ГДЕ    — components/focus-session.tsx:
         initialMinutes = durations.includes(d) ? d : 25
ЧТО    — органический заход на /app/session (таб «Фокус») получает
         дефолт 25 минут; в ряду [15, 25, 45] середина читается «нормой»,
         и 15 становится «меньше нормы» (compromise effect)
ПОЧЕМУ — манифест продукта — «планка на полу», чат-фолбэк обещает
         «начнём с двух минут» — а интерфейс не умеет меньше 15 и
         дефолтит в 25. Дефолт — самый сильный нудж; сейчас он давит
         вверх, против бренда
ВМЕСТО — дефолт 15 всегда; добавить ступень 5 минут (лестница [5, 15,
         25, 45] или [5, 15, 45]); для интентов feelBad/distracted из
         чата — передавать d=5. Шансы редкости не трогать: короткая
         сессия честно остаётся normal-odds
```

## 2.1 Первые пять секунд

Лендинг считывается верно: «живое существо, не приложение». Кот — самая

```
ГДЕ    — components/landing/hero.tsx, мобильный кадр
```

3 тапа до работающей сессии, без регистрации — уровень лучших

Конкретные точки срыва: дефолт 25 минут (см. 1.5) и обрыв гиперфокуса:

```

ЧТО    — на нуле таймер молча обрывает работу и выбрасывает на экран
         награды со звуком
ПОЧЕМУ — если человек вошёл в поток (цель продукта!), принудительный
         обрыв на пике — наказание за успех. Гиперфокус хрупок и ценен
ВМЕСТО — на нуле: пауза и одна строка «Время вышло. Забрать находку — или
```

## 2.4 Мотивация и возврат

Работает и работает честно: остров без отката, старт как валюта, pity,
goal gradient, ночные весточки и дневник отсутствия (вариативные, из
реальных данных), однотаповый план на пике, бейдж непросмотренного мира.

Две дыры помимо слоя 1:

```
ГДЕ    — lib/memory.ts (localStorage) против обещаний «навсегда» по всему
         продукту
ЧТО    — Safari ITP стирает site data после 7 дней неиспользования
         неустановленного сайта; чистка браузера стирает всё везде
ПОЧЕМУ — эмоциональный контракт — «что выросло — выросло навсегда» и
         «всё ждёт тебя ровно там, где ты оставил». Человек, вернувшийся
         после паузы — ровно тот, под кого написан дневник отсутствия —
         может встретить пустой берег. Это предательство в терминах
         собственного нарратива; одного случая хватит для невозврата
ВМЕСТО — слоями: navigator.storage.persist() (одна строка) → зеркало
         памяти в IndexedDB (инфраструктура уже есть в checkin.ts) →
         кнопка «унести остров с собой» (экспорт/импорт JSON) → позже
         опциональный синк
```

```
ГДЕ    — lib/island-elements.ts, ISLAND_POOL: 16 элементов, 4 редких
ЧТО    — у ежедневного пользователя коллекция собирается за 2–4 недели,
         дальше «остров густеет» дубликатами — variable reward умирает
         у самых вовлечённых
ВМЕСТО — оси вариации дешевле новых спрайтов: сезон/погода (те же
         спрайты в снегу), эволюция ориентиров (дерево растёт с числом
         стартов рядом), редкие СОБЫТИЯ вместо объектов (кит приплывает
         на день — и об этом хочется рассказать, см. 3.1)
```

## 2.5 Тёмные паттерны

Продукт декларирует «без стыда, без стриков» и держит слово: runningDays
намеренно не показывается и не передаётся LLM, уведомление одно в день без
«ты пропал», ноль фальшивой срочности и таймеров потери.

Найденное:

```
ГДЕ    — focus-session.tsx (running-экран), island.tsx (витрина)
ЧТО    — «полная сессия повышает шанс редкой находки» показывается и в
         стартах 1–10, когда drawFind() вообще не вызывается: награды
         детерминированы, никаких шансов нет
ПОЧЕМУ — фактическая неправда в продукте, построенном на честности:
         человек досиживает ради несуществующего шанса — манипуляция,
         пусть и по недосмотру
ВМЕСТО — условие totalStarts >= LANDMARK_COUNT; до этого — «старт уже
         засчитан · следующий вырастит „Костёр“»
```

- Скрытие таб-бара в сессии + строка про шанс редкого — мягкие «клещи
  удержания»; по отдельности честны («Закончить раньше» на экране,
  бонус без штрафа). Оставить, третьего давления не добавлять.

Механики, которые подняли бы метрики — и почему нет:
- **Стрики** — подняли бы D7, ломают «ноль — не минус»: первый срыв
  конвертируется в отток с виной.
- **Саспенс-рулетка при выпадении** — поднимает пиковый дофамин,
  превращает награду за старт в азартный автомат. RevealIsland
  сознательно не делает — верно.
- **Декей острова («вянет без тебя»)** — сильнейший страх-потери-триггер,
  прямо противоречит «мир не откатывается». Никогда.
- **Охрана выхода («точно бросишь?»)** — плюс к длине сессии, минус к
  доверию.

## 2.6 Что вырезать

1. **Рукописную приписку из мобильного hero** — третий голос в кадре.
2. **Витрину «Редкие события» для 0 стартов** — вернуть к 8–10 старту.
3. **hourLine из склейки приветствия** — отдельной репликой или в чат.
4. **Похвалу из голоса**: «Без пафоса: ты красавчик» (fallbackVoice.done),
   «Красавчик. Остров это тоже почувствовал» (scripted done) — канон
   голоса запрещает похвалу; «без пафоса» перед похвалой её не отменяет.
   Констатация уже есть и сильнее: «Начато и отработано. Остров стал
   чуть больше».
5. **Комментарий «метафора стрика» у огонька на хвосте** (mascot-svg.tsx)
   — в продукте, чей манифест «ноль стриков», даже внутренняя метафора
   стрика — заноза; огонёк оставить, смысл переименовать (очаг, не стрик).

# Слой 3 · Рост и измеримость

## 3.1 Пик дофамина не конвертируется ни во что

```
ГДЕ    — весь продукт; landing/world-section.tsx сам называет редкие
         находки «события, о которых хочется рассказать»
ЧТО    — у продукта ноль петель привлечения: ни шаринга, ни инвайта, ни
         SEO-поверхности кроме лендинга. Пик эмоции (редкая находка,
         собранный остров) испаряется в приватной вкладке
ПОЧЕМУ — маховик роста consumer-продукта строится на конвертации пиковых
         моментов в артефакты. Остров — готовая открытка: уникальный,
         личный, красивый
ВМЕСТО — «показать остров»: рендер SVG-острова в PNG-карточку (canvas,
         без сервера) с именем существа и числом стартов — по явному
         тапу, никогда автоматически. Плюс share-момент на редкой
         находке. Это единственная рекомендация роста; без неё продукт
         растёт только рекламой
```

## 3.2 Петлю нельзя настраивать вслепую

```
ГДЕ    — app/layout.tsx: только @vercel/analytics (pageviews)

         план, возврат по уведомлению, дарение имени — невидимы
```

# ТОП-8 по эффект/усилие

| # | Действие | Усилие | Что двигает |
|---|---|---|---|
| 1 | Расщепить награду: росток при старте, цветение в финале (1.1) | ~1 день | Ядро: подкрепление инициации |
| 2 | Дефолт 15 мин + ступень 5 мин + d=5 из «тяжёлых» интентов (1.5) | 1–2 часа | Активация в худшем состоянии |
| 3 | Убрать ложь про шанс редкого в стартах 1–10 (2.5) | 30 мин | Честность ядра |
| 4 | Лестница неопределённости наград 4–10 (1.2) | 2–3 часа | Живой RPE на онбординге |
| 5 | storage.persist() + IndexedDB-зеркало + экспорт острова (2.4) | 0.5–1 день | Контракт «навсегда» |

# Не трогать

- **RevealIsland** — награда прорастает на настоящем острове, без
  рулетки. Лучший экран продукта; пункт 1.1 его расширяет, не заменяет.
- **Философия «ноль — не минус»** везде, включая отказ передавать LLM
  «дней подряд».
- **Скриптовый мозг-фолбэк** — существо никогда не молчит и не показывает
  ошибку; анти-повтор реплик — ремесло уровня AAA.
- **Маскот** — моргание со случайным интервалом, зрачки за курсором и
  скроллом, двухточечное освещение, перф-гейт по IntersectionObserver.
  Это и есть «выглядит на миллионы».
- **Честный таймер** от абсолютного времени + восстановление сессии.
- **Однотаповый план на пике** и очередь дробления — цепь Зейгарник
  собрана правильно.
- **Pity с честным озвучиванием** («следующая будет необычной — или
  лучше») — variable ratio без обмана.
- **Материальная система** (.glass-ярусы, закон «UI не светится —
  светится мир»).

# Замечено по пути

- buildChatGreeting: плюрализация ломается на 21+ («Помню 21 твоих
  стартов») — образец правильной уже есть в pluralFinds().
- font-mono text-[10px] микрокопи — ниже гейта 12px, поднять где можно.
- `pb-16` на session-странице против `pb-20` на остальных.
- Длинный `task` на running-экране не обрезается (trimLabel есть —
  применить).
- Звук награды гейтится prefers-reduced-motion: движение ≠ слух; при
  появлении настроек — отдельный тумблер звука.
- runningDays вычисляется и нигде не используется — оставить как есть:
  это осознанная защита от соблазна стриков, зафиксировать комментарием.
